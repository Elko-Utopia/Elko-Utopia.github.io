V2.0.4 8 Milestones · 24 Releases 8 个阶段 · 24 次版本迭代

Website Development Log 网站开发日志

Every major milestone and detailed iteration of this site in reverse chronological order. Expand any release to inspect the full change list. 按时间倒序记录本站的每一次阶段演进与详细改动，点击任意版本卡片即可展开或收起具体更新内容。

  1. V2.0.4 13 changes 13 项改动
    1. Adopted the unified editorial typography system (Instrument Serif + Noto Serif SC + Inter + Noto Sans SC + JetBrains Mono) with proportional fluid body-to-heading scaling 全站落地策展画册字体体系（Instrument Serif + 思源宋体 + Inter + 思源黑体 + JetBrains Mono），保留随屏幕平滑缩放的等比字号层级
    2. Introduced a 3-level tonal surface token system (--bg, --surface, --surface-soft) for crisp contrast in both light and dark modes 建立三层表面色阶变量（--bg / --surface / --surface-soft），统一亮暗主题的层次对比
    3. Merged the article Table of Contents toggle into a comfortable sticky breadcrumb bar, eliminating redundant floating pills and duplicate headers 将文章目录开关合并至舒适高度的吸顶面包屑栏右侧，取消重复的悬浮胶囊与抽屉顶栏
    4. Unified outer hairline frames and single-radius clipping across the 3D planet viewer, 2D climate map, CompareSlider, galleries, tables, and portfolio cards (eliminating double rounding) 统一 3D 星球视图、2D 气候图、对比滑块、图库、各类数据表与独立配图的外包边与单次圆角裁剪，杜绝二次圆角
    5. Fixed English tectonic plate table text overlap and horizontal scrollbars, and aligned climate distribution table typography with plate tables 修复英文板块表文字重叠与横向滚动条问题，并使气候占比表与板块表采用同一套紧凑等宽数据排版
    6. Unified portfolio secondary category pages into cohesive cards wrapping both cover image (top-only radius) and title/date text, matching the top-level portfolio layout 将作品集二级分类页改造为与第一层一致的图文一体卡片，圆角延展包裹标题与日期，图片底端直角衔接文字
    7. Removed unwanted white border outlines around blog list thumbnails 移除博客列表封面图外侧的多余白色描边
    8. Fixed the search page tag dropdown clipping bug, turned the expand control into a dedicated dropdown button, removed heavy input shadows, and fixed search result card typography 修复搜索页「展开全部标签」按钮被裁切的问题，改用独立直角下拉控件替代伪装 Tag 胶囊，移除搜索框重阴影并修复结果卡片字体畸形
    9. Refined tag colors to a clear, balanced editorial palette while keeping neutral readable text, and unified all prose hyperlinks to body-colored text with blue underlines 优化标签色板为适度鲜明的编辑色阶（保持中性清晰文字），全站正文超链接统一为正文色 + 蓝色下划线，禁用蓝色字体模式
    10. Upgraded Header (sliding navigation pill/bar, cursor-lit hairline, magnetic icon buttons), Footer (clean borderless magnetic icons with floating labels), and Homepage Masonry (micro-parallax, cursor sheen, staggered overlay reveal without outer-box scaling overlap bugs) 重做顶栏（灵动滑动指示器、底边指针微光、轻磁吸图标）、页脚（无框纯净微磁吸图标与浮现标签）及主页瀑布流交互（内部微视差、指针微光与错峰说明浮现，根治外框放大叠压 bug）
    11. Refined circular View-Transition ripples: slower unhurried theme transition with zero frame-0 flash, plus a synchronized top-layer vector wavefront ring exclusively for language switching 优化明暗与语言切换的圆形波纹过渡：放慢明暗切换节奏并消除首帧闪现，为语言切换新增与扩散边界像素同步的顶层矢量光环
    12. Restyled in-game MakeCode Arcade virtual joystick and Z/X buttons to match the site theme, fixed swap interaction bugs, and added automatic layout reset on portrait-to-landscape orientation flip 重绘 MakeCode 小游戏虚拟摇杆与 Z/X 按键以贴合站点风格，修复左右交换后的操控 bug，并增加横竖屏切换自动复位
    13. Rebuilt the Website Development Log into this interactive collapsible timeline and removed legacy defensive inline scripts from BaseHead and AutoContentList 清理 BaseHead 与 AutoContentList 中的历史防御性冗余代码、减少页面加载闪烁，并将本页升级为可展开/收起的交互式版本日志
    V2.0.3 9 changes 9 项改动
    1. Built a Three.js interactive 3D planet viewer supporting 3D globe and three 2D world map projections (Robinson, Equirectangular, Mollweide) 引入 Three.js 构建交互式三维星球视图，支持 3D 球体与罗宾森、平面、摩尔威德三种世界地图投影自由切换
    2. Added multi-layer scientific visualization: surface, land/sea, 12-month temperature & precipitation playback, tectonic plates, live elevation contours, climate classification, and T85 hydrology rivers & lakes 支持多图层科学可视化：地表、海陆、12 个月气温与降水动态播放、构造板块、实时等高线、气候分类与 T85 水文河湖
    3. Embedded playable MakeCode Arcade games with unmuted audio, responsive volume slider, fullscreen toggle, and draggable virtual controls 集成 MakeCode Arcade 网页试玩页面，支持游戏声音与响应式音量滑条、全屏以及可拖拽虚拟手柄按键
    4. Added interactive image CompareSlider with adaptive divider contrast 新增前后对比滑块组件（CompareSlider），支持按画面明暗自适应分割线色调
    5. Migrated to single-URL instant EN/ZH switching synced with URL parameters (?lang=&theme=#hash), unified bilingual tag registry, and cross-language search v2 升级单 URL 即时中英双语切换与地址栏状态同步（?lang=&theme=#hash），统一双语标签注册表与跨语言搜索 v2
    6. Added procedural HiDPI Canvas rendering for the animated vortex SiteLogo, cursor-reactive SiteTitle, and ambient dot-matrix background 新增程序化 HiDPI Canvas 漩涡徽标、指针光斑标题动效与全局微星尘点阵背景
    7. Added an article Table of Contents sidebar generated automatically from headings with expand/collapse, scroll-spy, and responsive layout adaptation 新增自动解析正文标题的文章侧边目录，支持展开收起、滚动定位与宽窄屏自适应避让
    8. Added direct original-file GIF playback in homepage masonry cards and configurable multi-column Markdown galleries with below-image captions 首页瀑布流支持原文件播放 GIF 动图，扩展 Markdown 画廊支持自定义列数与图下常驻说明
    9. Resolved 3D close-zoom scroll twitching and double scrollbars by removing Lenis scroll hijacking and clamping globe touch/wheel hit testing 移除 Lenis 滚动劫持并收紧球面滚轮命中判定，彻底消除 3D 近距缩放与双滚动条抽搐问题
